# 🤖 Хелпер (Helper Bot 7-V)

Асинхронний шкільний екосистемний Telegram-бот для автоматизації навчального процесу, обліку відвідуваності, доступу до підручників НУШ та гейміфікації шкільного життя.

## 🚀 Startup

Бот ініціалізує роутери `aiogram`, піднімає фоновий веб-сервер `aiohttp` для моніторингу та запускає планувальники завдань за київським часом (`Europe/Kiev`):

```text
⚡ Helper Bot ready — booted on Python 3.11 + aiogram 3.x
```

Усі ключові модулі (машина станів FSM, рольова модель доступу RBAC, таймер привітань та локальне сховище JSON) інтегровані в єдиний асинхронний цикл без важких зовнішніх БД.

## 📦 Install & Local Run

```bash
# 1. Клонування репозиторію
git clone https://github.com
cd ТВІЙ_РЕПОЗИТОРІЙ

# 2. Встановлення залежностей
pip install -r requirements.txt

# 3. Запуск бота (попередньо вкажіть BOT_TOKEN у main.py)
python main.py
```

## ☁️ Cloud Deploy (Render)

Для безперервної роботи 24/7 проєкт адаптований під деплой на **Render** як Web Service:
- **Build Command:** `pip install -r requirements.txt`
- **Start Command:** `python main.py`
- Вбудований `aiohttp` сервер слухає порт середовища (`PORT`, за замовчуванням `8080`) та обробляє `GET /` запити для підтримки активності інстансу.

## 🗂️ Project Structure

```text
├── main.py              # Основна логіка бота, хендлери, FSM та фонові воркери
├── requirements.txt     # Залежності проєкту (aiogram, aiohttp)
```

## 📋 Commands & Roles (Cheat Sheet)

### Команди користувачів та адміністраторів

| Command | Description | Access |
| :--- | :--- | :--- |
| `/start` | Ініціалізація профілю та відкриття головного меню | Усі учні |
| `/help` | Виведення актуального списку доступних команд | Усі учні |
| `/pay @user сума` | Переказ внутрішньої валюти «Сімки» іншому учню | Усі учні |
| `/duel @user сума` | Виклик однокласника на дуель у режимі «Чат класу» | Учасники чату |
| `/give_coins @user сума` | Емісія та нарахування валюти на баланс учня | Розробник / Admin L4 |
| `/test_bd Ім'я` | Тестовий запуск привітання з Днем народження (+200 🪙) | Розробник / Admin L4 |

### Рольова модель доступу (RBAC)

| Level | Role | Permissions |
| :--- | :--- | :--- |
| **Level 0** | Учень | Розклад, ДЗ, бібліотека НУШ, ШІ-помічник, чат, магазин |
| **Level 1** | Помічник | Редагування домашніх завдань (`Admin Panel`) |
| **Level 2** | Староста | Зміна розкладу, облік відсутніх, звіти класному керівнику |
| **Level 3** | Модератор | Модерація чату класу (мут, блокування порушників) |
| **Level 4** | Admin / Dev | Повне керування правами, премодерація досягнень, тест-режим |
